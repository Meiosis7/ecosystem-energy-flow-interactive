# 生态系统的能量流动｜一生儿 · 高中生物一本通

高中生物《选择性必修2 生物与环境》漫画风交互教学模型。

[打开在线演示](https://meiosis7.github.io/ecosystem-energy-flow-interactive/)

## 演示内容

- 生产者、初级消费者、次级消费者的能量去向，点击金色提示逐步展开。
- 摄入量 → 扣除粪便中的能量 → 同化量，按同一份能量连续追踪。
- 全程总览、呼吸散失、分解途径和相邻营养级的能量传递效率。
- 示例数值、一定时间内的去向、自动演示、全屏和动态效果开关。
- AI生成漫画背景与生物素材，适合课堂投屏。

## 使用

直接访问在线演示，或下载 `energy-flow-offline.html`，在浏览器打开即可离线使用。

源文件为 `index.html` 和 `assets/`，部署无需构建或外部服务。在线版使用轻量WebP图片，PNG源图与自包含离线版一并保留。

## 教学说明

数值为教学示例，不是生态系统实测数据。示例中的60%同化比例不等于相邻营养级10%～20%的能量传递效率。粪便中的能量未被该消费者同化，仍属于上一营养级；分解者不是食物链的最后一个营养级。画面大小、箭头宽度与粒子速度均不表示真实能量比例。
